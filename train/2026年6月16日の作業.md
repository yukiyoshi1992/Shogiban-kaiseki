# 将棋盤画像解析ツール

将棋盤を撮影した画像からKIFファイルを自動生成するツール群。

## 全体の流れ

```
[対局開始] 0手目画像
   ├─ 赤丸検出 → 盤の4隅 → キャリブレーション（マス座標確定）
   └─ 青三角検出 → 頂点方向 → 盤の向き確定
        ↓
[各手] 1手ごとの画像
   ├─ 盤面を9×9マスに切り出し
   ├─ 駒認識モデル（MobileNetV2）で各マスを判定
   ├─ 前の盤面との差分 → 動いた駒を特定
   ├─ python-shogiで合法手チェック
   └─ KIFに追記
        ↓
[対局終了] KIF確定出力
```

## ディレクトリ構成

```
Shogiban-kaiseki-tool/
├─ train/
│  ├─ data/
│  │  ├─ data0〜8（学習用画像・KIF）
│  │  ├─ cells/        切り出した駒画像（ラベル別フォルダ）
│  │  ├─ 対局/         方向テスト用の連続対局データ
│  │  ├─ 成り駒/       成り駒の追加学習データ（10パターン）
│  │  └─ 青三角データ/ 向き判定テスト用
│  ├─ models/          学習済みモデル（best_model.pth等）
│  └─ src/             学習・準備用スクリプト
├─ runtime/
│  ├─ input/           本番: 監視対象フォルダ（画像が同期される）
│  └─ result/          本番: KIF出力先
└─ src/                本番用スクリプト
```

## 座標系（重要）

画像を「先手が左」の向きにした状態で：
- `row` = 0(上=9筋) 〜 8(下=1筋)
- `col` = 0(左=先手側1段目) 〜 8(右=後手側9段目)
- shogi square変換: `square = (8-col)*9 + row`

## 駒ラベル（29クラス）

```
empty
先手: sente_{fu,kyo,kei,gin,kin,kaku,hi,ou,
            tokin,nari_kyo,nari_kei,nari_gin,uma,ryu}
後手: gote_{同上}
```

- 盤面認識精度: 99.9%（学習データ）

- 残課題: 成り駒（特にsente_uma=1枚）の学習データ不足
