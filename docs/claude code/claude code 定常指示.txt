画像の確認などは人間がやったほうが確実な部分が多いと思いますので
無理にいろいろ推測せずこちらに確認してください。

例）XXXX.jpgは先手はどっちにむいているか？XXXX.jpgのキャリブレーションがあっているか画面で確認してほしい　など


あと、学習まえにできるだけ人間側で確認をしたいです。
たしかキャリブレーションに誤りがないことは全データ確認済ですよね？
駒画像とラベルに誤りがないかもざっと確認できるといいですが、
例によって件数が多すぎるので効率よく確認をいただく必要があります。

・空白マス画像は確認しない
・それぞれの駒について200パターンくらいランダムで取り出し、
　ラベルに対する駒画像をできるだけ一気に画面いっぱいに表示。
　誤っているものがないかを人間が目視確認する
